Malom Perfect Database

The Malom perfect database (by Gábor E. Gevay & Gábor Danner) provides exact Win/Draw/Loss values for every legal position. It is a large external download not included in the IA bundles above. Point this to the directory containing the .sec2 sector files after extracting. Changes take effect after a server restart.
