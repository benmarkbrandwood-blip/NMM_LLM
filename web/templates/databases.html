Getting the Malom Perfect Database

The Malom perfect database was created by Gábor Danner and Gábor E. Gévay (University of Szeged, Hungary). It provides an exact Win/Draw/Loss value for every legal Nine Men's Morris position, enabling the Perfect DB overlay and Malom adjudication features. Source code is available under GPLv3 at github.com/ggevay/malom.

The Standard rules variant is what this game uses. It is distributed via BitTorrent — use any torrent client to download it.

  1. Download the torrent: Malom Standard Ultra-strong v1.1.0 — 12 GB compressed · 78 GB uncompressed.
  2. Open it in a BitTorrent client (qBittorrent, Transmission, etc.) and download to a permanent location on a drive with enough free space.
  3. Locate the extracted folder — it should contain many .sec2 sector files (e.g. Std_DD_89adjusted/).
  4. Paste the folder path into the configurator below and click Save.

Windows: the Gábor binaries (Malom_binaries_1.1.0.zip, 2.7 MB) include a standalone solver application for querying positions outside the game. Requires .NET Framework 4.5 on 64-bit Windows. Download the binaries separately — the database torrent above works on all platforms.
