🔎 AI Overlay Guide

← Game Game / Opening Explorer

Overlays show per-move scores from neural networks and databases, helping you understand and analyse each position. Select up to three in the analysis panel dropdowns; toggle diagnostic chips for additional annotation layers.

Move-Score Overlays

Three dropdown slots in the analysis panel. Each colours move arrows on the board by the selected model's score for that move.

S: Sentinel Neural move-quality scorer
What it shows Scores each legal move 0–1 (1 = winning, 0 = losing) from the current player's perspective.
Training Trained on AI vs AI and human games with Malom database win/draw/loss labels. A contrastive ranking loss ensures winning moves rank above losing moves within each position.
G: GapNet Positional gap evaluator
What it shows Estimates positional vulnerability after each move. Lower G: scores indicate safer resulting positions.
Training Trained on game outcome data to identify positional gaps. GapNet v3 is a calibrated neural network; v1 is an older fallback if v3 is unavailable.
V: ValueNet Position value predictor
What it shows Predicts the long-term win probability of the resulting position. Higher V: = stronger position for the mover.
Training Phase-specific model (v3): separate networks for placement, movement, and fly phases, trained with DTW-weighted game outcome targets. Promotes decisive outcomes.
F: PrefNet Human preference ranker
What it shows Ranks moves by how likely a human player is to choose them. F: values are normalised probabilities.
Training Trained on over 22,000 human games (640,000+ positions) using a pairwise ranking loss. Strongest in constrained late-game positions where move choices are limited.
H: Hum% Human move probability
What it shows Predicted probability (%) that a human player at the selected Elo band would play each move. Use the band selector to filter by strength.
Training Teacher v4 model, trained on 22,000+ human games with log-scaled branching-factor weighting. Also serves as a training opponent for the Generalist AI at a 25% humanlike blend.
Gen: Generalist AI pick probability
What it shows Probability (%) that the Generalist AI would pick each move in this position. Gen: 100% means it always picks that move here.
Training ScaffoldedPolicyNet trained through reinforcement learning with heuristic scaffolding and 25% human-teacher opponent blending. Expert features include Sentinel scores, heuristic evaluations, and Malom WDL signals.
R: Regret Malom counterfactual cost
What it shows How much worse a move is compared to the Malom-optimal move, measured in depth-to-mate units. R: 0 = optimal. Higher values = more costly deviation.
Source Computed directly from the Malom perfect database (DTM values). Only meaningful when Malom is installed. Requires Malom DB to be configured in Databases.

Diagnostic Overlays

Toggle buttons in the analysis panel. Each adds an annotation layer to all legal moves simultaneously, and can be combined with the net-slot overlays.

Static Fast heuristic evaluation
What it shows Tactic bonus (mill threats, piece count, mobility) plus position evaluation for each move. Instant — no lookahead.
Source Classic NMM heuristic function used by the AI engine for move ordering. Useful for a quick sanity check of the tactical situation.
Negamax d3 Deep search scores
What it shows Alpha-beta search score for each move at the selected depth (default 3 plies). Slower to compute — refreshes once per position request.
Source Uses the same negamax engine as the AI player, with transposition table and move ordering. Disabled while the AI is calculating its own move.
Traj/Hum Human trajectory + Hum% fallback
What it shows T: = % of human games in the database that used this move from this exact position. H: = Hum% model probability when no trajectory data exists for a move (T:—).
Source T: data is indexed from 22,000+ human games. When a position has never been seen in the database, H: falls back to the Hum% model for an Elo-conditioned estimate.
DB/Malom Perfect database annotations
What it shows WIN (green) or LOSS (red) arrows from the endgame and Malom databases. Shows M# (moves to forced mate) where Malom data is available.
Source Three layers: FullGame DB (common human game positions), retrograde Endgame DB (all ≤11-piece positions, perfectly solved), and the Malom perfect database (complete game tree). Malom requires separate installation.
Opp. Pressure Opponent response analysis
What it shows For each move you can make, shows L: % (green) of opponent responses that are losing for them, and W: % (red) that are winning for them. Choose moves that maximise L:.
Source Computed from the Malom perfect database by evaluating all opponent responses to each candidate move. Requires Malom DB. Helps identify moves that give the opponent the most chances to err.
AI Choice Generalist AI pick probability
What it shows O: % — how likely the Generalist AI is to choose each move in this position. Highlights the AI's preferred move and how it distributes probability across alternatives.
Source Same ScaffoldedPolicyNet as the Generalist net-slot overlay, displayed as a chip annotation rather than a colour scale. The chip button is dimmed if the Generalist model has not loaded.
